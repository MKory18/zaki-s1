# قواعد الكود والتسمية

ملزمة لكل مهمة. من برومبت B00 وخطة البناء.

1. **التسمية:** الأسماء بالإنجليزي (مجلدات، ملفات، جداول، حقول، متغيّرات). الواجهة والنصوص والتقارير والتعليقات بالعربي. مفاتيح JSON بالإنجليزي.
2. **المبالغ:** `Decimal` دقيق. ممنوع الأرقام العائمة للمال. التواريخ بتوقيت مع المنطقة، والمنطقة الافتراضية `Asia/Amman`.
3. **الأرقام:** كل رقم بيطلع من وحدة `src/core` وإله قاعدة مكتوبة. ما في حساب مخفي بالواجهة أو بالبرومبت.
4. **الموديلات:** كل استدعاء موديل بيمرّ من البوابة `src/gateway`. ممنوع استدعاء مزوّد مباشرة.
5. **الأسرار:** ولا سر بالكود ولا بالسجلات ولا بالاختبارات ولا بأي برومبت. الأسرار بملف `.env` على السيرفر بس، و`.env.example` فيه الأسماء بلا قيم. المتصفح والإضافة بيحكوا مع النظام بس. فحص `npm run secrets` لازم يطبع «نظيف».
6. **الصلاحيات:** كل API بيفحص الدخول والصلاحية، وبيرجع أخطاء بالعربي بشكل موحّد.
7. **التدقيق:** كل تعديل أو قرار بيتسجّل (مين، شو، على أي سجل، قبل وبعد، متى).
8. **الاختبارات:** إلزامية للحسابات (أمثلة ملف المنطق بأرقامها حرفياً). ما في «خلصت» بلا اختبارات ناجحة.
9. **التقارير:** بالعربي.
10. **المال والإرسال الخارجي:** الوكلاء بيقرأوا وبيكتبوا مسودات بس. ولا أداة إرسال خارجي ولا دفع. أي شي فيه مال بيفتح رابط الموقع للموافقة.
11. **حدود المهمة:** مهمة وحدة بكل مرة. أي اقتراح برّا المهمة بينسجّل بـ `PROGRESS.md` ولا بينفّذ.

## الشحن

- كل دمج على `main` بينشر الصورة ويقول لكوليفاي ينشر.
