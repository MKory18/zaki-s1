## الجزء الأول — طريقة البناء

### 1. مين بيبني وكيف

- البنّاء: GLM بالفايب كودنج، وإنت بتوجّه وبتجرّب. ما في حاجة تكون مبرمج.

- المرجع: ملفات Word الستة بتتحوّل لملفات نصية بمجلد docs داخل المشروع (برومبت D0)، وGLM بيقرأ منها كل جلسة.

- الذاكرة بين الجلسات: ملف PROGRESS.md (شو انعمل وشو باقي) وملف CONVENTIONS.md (قواعد الكود والتسمية) — GLM بيحدّثهم آخر كل مهمة.

- الإيقاع: مهمة وحدة لكل جلسة: U1 ← برومبت المهمة ← GLM بيطبع خطة ← بتوافق ← بيبني ويشغّل الاختبارات ← تقرير عربي ← بتجرّب بإيدك حسب «كيف تتأكد» ← حفظ نسخة (commit) ← المهمة الي بعدها.

- الترتيب: الباك إند أولاً لكل وحدة، بعدين شاشتها بشكل وظيفي، والتصميم النهائي والجوال بالآخر.

### 2. المكدس التقني

| الطبقة | الأداة | ليش |
|---|---|---|

| الطابور والجدولة | BullMQ مع Redis | مهام الوكلاء والسحب الليلي بأوقاتها |

| الدخول | الهوية المشتركة لأنظمة Zaki (OIDC) | تسجيل دخول واحد |
| الموديلات | بوابة متوافقة مع OpenAI | GLM · Kimi · Claude · Gemini · داخلي |
| الموديلات الداخلية | سيرفرك (واجهة متوافقة مع OpenAI) | التضمين · الترجمة · التصنيف · حَكَم المكرر |
| بصمة الصور | مكتبة pHash على الصور | دمج المكرر |
| تيليجرام | بوت بسيط بالعامل (worker) | التقارير والتنبيهات |

- نسختين: تطوير (على جهاز أو سيرفر تجربة) وإنتاج (السيرفر الحقيقي)، وكل وحدة بتنجرّب بالتطوير قبل الإنتاج.

#### T3.03 — المصادر الرسمية والاستيراد

- علي إكسبرس: بحث المنتجات والرائج وتفاصيل المنتج بالواجهة الرسمية، بكلمات خريطة المشاكل، ليلياً.

- جوجل ترند: الواجهة الرسمية إذا انقبل الطلب، وإلا استيراد ملف من الموقع.

المثال للشكل بس؛ المحددات الحقيقية بتنكتب وقت البناء وبتتحدّث عن بُعد من شاشة الإضافة بلا إعادة تثبيت.

### 4. القواعد

| القاعدة | القيمة الافتراضية |
|---|---|
| التبويبات بوضع القائمة | تبويب واحد بكل مرة |
| بين صفحة وصفحة | عشوائي بين 45 و90 ثانية |
| الحد الساعي | 40 صفحة |
| الحد اليومي | 200 صفحة |
| استراحة | 10 دقايق كل 20 صفحة |
| إشارة توقف | توقف كامل للقائمة + تنبيه، والاستئناف منك بعد ما تحل الموضوع بإيدك |
| 3 فشل متتالي | توقف + «المحددات بدها تحديث» |
| حقول ناقصة | نص الصفحة (بلا قسم التعليقات) + لقطة لمنطقة المنتج، والاستخراج على الخادم |
| الخصوصية | حذف الإيميلات وأرقام الهواتف من النص قبل الإرسال · التعليقات بتنعدّ بالإضافة نفسها وبيروح العدد بس |
| الصلاحيات | المواقع المدعومة بس، بلا «كل المواقع» |
| التوكن | توكن جهاز من شاشة الإضافة، بينحفظ بالإضافة، والخادم بيحفظ بصمته بس |
| التحديث | فحص النسخة عند التشغيل، وشريط «في نسخة جديدة» برابط التنزيل |

خطر: إضافة بصلاحية «كل المواقع» وبتلف على الصفحات لحالها بالخلفية، بتصير بوت سحب آلي، وبتنحظر الحسابات وبتخالف الشروط.

التصحيح: صلاحيات المواقع المدعومة بس، وولا تصفّح بالخلفية؛ وضع القائمة بيشتغل بس على روابط إنت حطيتها، وبالحدود فوق، وبيوقف عند أي تحقق.

### 5. التثبيت

- من شاشة الإضافة بالنظام: «نزّل الإضافة» (ملف مضغوط) ← فك الضغط ← كروم: الإضافات ← تفعيل وضع المطوّر ← تحميل غير مضغوط ← اختار المجلد.

- من شاشة الإضافة: «جهاز جديد» ← انسخ التوكن ← الصقه بخيارات الإضافة ← «متصل».

## الجزء الثالث عشر — تعريف «منجز» وما بعد الإطلاق

- الاختبارات التلقائية كلها ناجحة.

- PROGRESS.md محدّث بالعربي: شو انعمل · كيف أجرّب · شو المعلّق.

- علي إكسبرس الرسمي + الإضافة بمحوّلي علي إكسبرس ومكتبة إعلانات ميتا + الاستيراد.

- الدمج والمرحلتين والبطاقة والتقرير الصباحي وتيليجرام.

- بوابة الامتثال والمكتبات.
