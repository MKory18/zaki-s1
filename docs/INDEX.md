# فهرس المرجع

ملفات Word الستة الأصلية بتضل بهالمجلد، والنصوص أدناه (من `tools/docx_to_md.py`) هي اللي بيقرأها كل جلسة. إذا تعارض شي، الملف الأصلي بيغلب.

| الملف | شو فيه |
|---|---|
| `01-logic.md` | المنطق والأقسام: الحاسبة، مؤشر السرعة، الحمض، القرار، الامتثال، الاستشاري، جدول التنبيهات، القرارات الست |
| `02-plan.md` | خطة البناء بالخطوات: المكدس، الهيكل، الأسرار، الأيام السبعة، نموذج البيانات، الجدولة، واجهات API، الإضافة، الاختبار، التشغيل |
| `03-design.md` | التصميم والشاشات: هوية «وُضوح»، المكوّنات، الشاشات، الجوال |
| `04-seeds.md` | المكتبات والبذور: خريطة المشاكل، النصوص المرجعية، المكونات، المحظورات، الأوزان، الافتراضات |
| `05-integration.md` | الربط بالأنظمة: عقود الأنظمة الثمانية، الأحداث، التواقيع |
| `06-prompts.md` | برومبتات GLM: U1 وD0 وB00–B20 وF1–F6 وبرومبتات الوكلاء A01–A17 وH01–H02 وK1–K3 |
| `CONVENTIONS.md` | قواعد الكود والتسمية (ملزمة) |
| `PROGRESS.md` | شو انعمل وشو باقي |
